# 小红书页面探针

以全新非持久 Chromium 中当前匿名访客可见的页面为第一事实。只执行公开页面浏览、读取和本地证据保存，不登录、不写入、不绕过登录墙，不把旧选择器、接口或单次样本当作稳定合同。

## 开始前

1. 读取根目录 `AGENTS.md`、`spec.md` 和 `.agents/skills/puppy-dev/SKILL.md`。
2. 检查工作区、Python/Playwright 环境、当前入口和 `.gitignore`；保留 `XhsPost（人工）.py`，不得修改、迁移或删除。
3. 明确公开入口、可选关键词与停止合同：按结果数、按时长或持续漫游。
4. 使用全新、非持久 Playwright Chromium，不加载、不导入且不保留 Cookie、localStorage 或账号资料。
5. 将探针证据放入 Git 忽略的 `.puppy-probe/xiaohongshu/`，产品运行证据放入 Git 忽略的 `.puppy/evidence/`；不得提交个人数据或会话信息。

## 实时决策原则

- 每一步先读取 DOM 和保存当前视口证据，再执行一个页面动作，然后重新观察。
- 页面重绘、滚动、路由或弹层变化后废弃旧元素句柄和临时定位结果。
- 只使用正常浏览器能力和公开可见控件；不伪造指纹、不隐藏自动化标志、不处理验证码、不直接调用或逆向页面接口。
- 导航、滚动、打开详情、读取详情和关闭详情前均重新检查登录弹窗；登录窗不是一次性状态。
- 出现验证码、安全校验、频率提示、不可关闭的阻断登录墙、浏览器断开或持续网络失败时停止当前动作，保存现场，不尝试绕过。

## 与通用总控的边界

- 通用总控拥有任务生命周期、关键词、按结果数/时长/持续模式的停止合同、跨平台调度、本地存储、幂等去重、证据索引和未来 AI 总结。
- 本探针只拥有小红书页面状态、登录弹窗、搜索与推荐流、滚动容器、详情开关、可见内容、有限评论、平台门禁和恢复结果。
- 探针返回统一观察对象：`platform`、`resource_type`、`resource_id`、`source_url`、`metadata`、`content`、`comments`、`evidence_refs`、`limitations` 和 `observed_at`。
- AI 不持有 Playwright 页面，也不生成选择器或点击动作；它只能消费已经落盘的观察对象，页面失败不能被摘要层改写成成功。

## 当前已验证页面事实

### 2026-08-04 匿名只读

- 登录弹窗可能在首个 DOM 稳定瞬间之后延迟出现；实测外层为 `.reds-modal.login-modal`，局部关闭候选为 `.icon-btn-wrapper.close-button`。
- 登录弹窗会在打开笔记详情后再次出现，因此每个页面动作前都要运行守卫。15:52 的产品主干短任务在列表和详情阶段分别关闭一次。
- 弹窗关闭后文档滚动有效。探针样本累计识别过 31、66 个唯一笔记；15:52 的产品主干推荐流识别 30 个当前可见 ID。
- 笔记详情表现为 `/explore/<笔记ID>` 路由与遮罩并存，详情滚动候选为 `.note-scroller`；`.close-circle` 可关闭详情并恢复列表。
- 匿名详情可读标题、作者、正文、标签、媒体形态和有限评论。一个显示评论总数 1092 的样本只渲染 10 条主评论、19 个评论节点，随后显示“登录查看全部评论内容”。
- 15:52 的产品主干读取 1 篇视频形态笔记、正文和 5 条可见评论，正确记录 `comments_truncated_by_login` 与 `video_media_not_interpreted`，并保存 PNG、脱敏 HTML 和有限文本证据。
- 本次产品主干尚未真实验证匿名关键词搜索与图片笔记，不得写成已经闭环；也不支持视频画面、音频或完整评论理解。

### 2026-08-02 页面结构候选

- 关键词 `AI Agent` 曾通过可见搜索框进入 `/search_result_ai`，结果链接形如 `/search_result/<24位十六进制ID>`。
- 搜索区曾出现两个重叠 `textarea`；必须结合可见性、边界与 `elementFromPoint` 选择当前命中层，不能固定第一个节点。
- 搜索结果滚动对象是窗口文档，且使用虚拟列表；跨轮累计唯一 ID，不能把当前 DOM 数量当作累计结果。
- 连续滚动累计 139 个 ID 时仍有新增，没有可证明的有限底部；必须报告停止原因，不能声称滚到底。
- 整页截图会触发滚动监听并可能重置位置；运行阶段只截当前视口。

## 登录弹窗守卫

1. 读取当前页面、可见弹层、遮罩与目标控件命中层，短暂观察延迟弹窗。
2. 若确认 `.reds-modal.login-modal` 或等价登录遮罩阻断页面，只点击其局部可见关闭控件；候选 class 每轮重新验证。
3. 验证弹窗消失且目标页面恢复可交互，保存关闭前后视口证据。
4. 没有关闭控件、关闭后立即重现、出现验证码或安全门禁时停止当前动作；不点击登录，不刷新循环规避门禁。

## 匿名浏览闭环

1. 打开公开推荐页；只有存在可验证搜索框时才通过可见控件提交关键词，不直接拼接未验证搜索 URL。
2. 运行登录弹窗守卫，记录脱敏 URL、视口、当前唯一笔记 ID、滚动指标和有限文本。
3. 从当前可见且未访问的 `/explore/<24位ID>` 或 `/search_result/<24位ID>` 中选择一个，打开后重新运行守卫并确认详情形态。
4. 读取实际呈现的标题、作者、正文、标签、时间、媒体形态和有限评论；滚动 `.note-scroller` 或本轮重新识别的详情容器，跨轮去重评论。
5. 遇到“登录查看全部评论内容”时记录 `comments_truncated_by_login`，不把展示总数冒充已获取数，不登录解锁。
6. 保存统一观察对象，以及当前视口 PNG、脱敏 HTML 和有限可见文本。
7. 关闭详情，确认遮罩消失与列表恢复，再滚动实际结果容器发现下一批笔记。

## 搜索、滚动与停止

- 搜索提交后同时等待结果 ID 集合与页面状态发生可观察变化；URL 变化不能单独证明成功。
- 同时检查窗口和可见滚动元素的 `scrollTop`、`scrollHeight`、`clientHeight` 与 `overflowY`，每轮只滚动排名最高的一个候选。
- 虚拟列表跨轮累计稳定笔记 ID；页面节点减少不代表结果丢失。
- 按数量任务达到目标后停止，按时长任务累计运行达到目标后停止。
- 持续漫游没有固定篇数、页数或滚动轮数上限，只在 owner 停止、安全门禁、连续多轮无位置与内容增量、来源耗尽、浏览器退出或网络失败时结束；不得无等待空转。

## 证据与隐私

- 每次运行保存 `summary.json`、`events.jsonl`、当前视口截图、脱敏 HTML 和有限文本；详情关闭前关联观察证据包。
- 禁止保存 HAR 请求体、Cookie、Authorization、localStorage、签名参数、完整媒体或完整带查询参数 URL。
- HTML 证据移除脚本、输入值与资源查询参数；观察与事件中的 URL 去除查询参数。

## 失败处理

- 定位、点击或等待失败时先保存现场，再依据刚读取的结构最多尝试 3 种有事实依据的候选。
- 搜索提交后结果不变、详情形态无法判断、存在结果但滚动对象不明或关闭后列表未恢复时暂停，不刷新丢失现场。
- 验证码、安全校验、频率提示、不可关闭登录墙、页面关闭或浏览器断开时立即停止自动操作。

## 验证与交付

1. 在真实匿名页面验证推荐流或可见搜索、登录弹窗关闭、至少一个详情读取和列表恢复。
2. 分别报告图片、视频、评论截断、搜索和持续漫游的已验证与未验证项，不制造测试。
3. 确认每条成功观察关联 PNG、脱敏 HTML 和有限文本，浏览器关闭后临时资料目录删除。
4. 检查 `.puppy/` 与 `.puppy-probe/` 已被忽略，工作区不包含会话资料或页面证据。
5. 修改项目实现时运行最接近变更的测试；更新本 skill 后运行 `skill-creator` 的 `quick_validate.py`。

交付时区分仓库静态检查、真实页面验证和未验证能力。未真实运行的页面能力不得写成已支持。
