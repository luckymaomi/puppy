# 哔哩哔哩页面探针

以匿名访客当前真实可见的页面为第一事实。探针只执行公开页面浏览、读取和本地证据保存，不登录、不写入、不绕过登录墙，不把旧选择器、页面接口或单次样本当作稳定合同。

## 开始前

1. 读取根目录 `AGENTS.md`、`spec.md` 和 `.agents/skills/puppy-dev/SKILL.md`。
2. 检查工作区、Python/Playwright 环境、当前入口和 `.gitignore`。
3. 明确公开入口、关键词与停止合同：按结果数、按时长或持续漫游。
4. 使用全新、非持久 Playwright Chromium 上下文，不加载、不导入且不落盘 Cookie、localStorage 或其他会话资料。
5. 将证据写入 Git 忽略的 `.xhs-probe/bilibili/<时间戳>/`，不得提交个人数据、会话信息或完整页面转储。

## 实时决策原则

- 每一步先读取 DOM 和保存当前视口证据，再执行一个页面动作，然后重新观察。
- 页面导航、滚动、分页、新标签页或弹层变化后，废弃旧元素句柄和临时定位结果。
- 只使用正常浏览器能力和公开可见控件；不伪造指纹、不隐藏自动化标志、不自动处理验证码、不直接调用或逆向页面接口。
- 登录提示按“阻断”与“非阻断”分类。只有遮挡目标、拦截点击或占据浏览上下文时才关闭；不能关闭但不阻断的提示记录后继续。
- 出现验证码、安全校验、频率提示、强制登录门禁、浏览器断开或网络持续失败时停止当前动作，保存现场，不尝试绕过。

## 与通用总控的边界

- 通用总控拥有任务生命周期、关键词队列、按结果数/时长/持续模式的停止合同、跨平台调度、本地存储、幂等去重、证据索引和 AI 总结。
- 本探针只拥有哔哩哔哩页面状态、登录提示分类、搜索分页、新标签页、视频元数据、Shadow DOM 评论、专栏可见性、平台门禁和恢复结果。
- 探针向总控返回统一观察对象：`platform`、`resource_type`、`resource_id`、`source_url`、`metadata`、`content`、`comments`、`evidence_refs`、`limitations`、`observed_at` 和 `next_cursor`。
- AI 不直接持有 Playwright 页面，也不生成选择器、分页或点击动作。它只消费已经落盘的观察对象进行分类、摘要和价值判断；页面失败不能被摘要层改写成成功。

## 当前已验证页面事实

以下事实来自 2026-08-04 的匿名真实页面，证据位于 `.xhs-probe/bilibili/20260804-120313-753885/`。它们只是下一次探测的优先候选，使用时仍要重新验证可见性、唯一性和命中层：

- 首页顶部 `v-popover` 登录提示没有可见关闭按钮，`Escape` 和移出均未使其消失，但它不阻断浏览；不得把它误判为必须清除的门禁。
- 右下角 `.login-tip .close` 可关闭，且已验证关闭后提示消失。选择器只是实测候选。
- 通过可见搜索框搜索“机器人总动员”成功；搜索页当前页识别到 41 个唯一视频结果。
- 搜索页滚动到底后进入分页结构，不是无限结果流。继续浏览必须识别并点击下一页，再验证结果集合变化。
- 点击视频通常打开新标签页。必须监听并捕获新 `Page`，不能只等待原搜索页 URL 改变。
- 匿名视频页实际可读标题、UP 主、简介、播放数据、发布时间和标签。
- 评论位于多层 Shadow DOM，已出现 `bili-comments`、`bili-comment-thread-renderer` 等宿主；普通页面选择器无法覆盖，必须递归遍历开放的 `shadowRoot`。
- 一个高互动样本匿名读取到 2 个评论线程，抽取到 3 个 DOM 文本节点（含层级重复），随后显示“登录后查看 58 条评论”。必须按线程与评论身份去重，并记录登录截断，不能声称读到全部评论。
- 评论脚本和页面自身评论请求在样本中返回 HTTP 200，这只证明页面自身加载成功；探针不得直接调用、重放或逆向这些接口。
- 专栏搜索标签可用，当时识别 20 个结果及其摘要。
- `cv3543806` 与 `cv50795889` 的匿名详情实测只显示登录壳，正文为空。当前只能支持专栏搜索结果摘要，不得承诺匿名读取专栏全文。
- 尚未验证视频画面理解、音频转写、字幕读取或金句提取；不得将标题、简介或评论推断为视频本体内容。

## 登录提示守卫

导航、打开视频、切换标签页、分页和滚动前后都重新检查可见覆盖层：

1. 枚举可见弹层、关闭控件、命中层和目标控件可交互性。
2. 对 `.login-tip .close` 或本轮确认的等价局部关闭控件执行一次关闭，并验证对应提示消失。
3. 对不阻断的顶部 `v-popover` 只记录，不反复按键、移动鼠标或点击未知区域尝试清除。
4. 对没有关闭路径且实际阻断目标的登录墙，记录 `login_blocked` 并结束当前分支，不点击登录入口。

## 匿名浏览闭环

### 1. 搜索与结果页

- 通过当前可见搜索框输入关键词并提交，不直接拼接未验证的搜索 URL。
- 等待新页面或新标签，并以结果 ID 集合和页面标题变化共同证明搜索完成。
- 记录当前页唯一视频或专栏 ID、标题、作者、摘要、可见统计、目标链接和页码。
- 滚动只用于暴露当前页延迟渲染内容；到达底部后识别分页控件。点击下一页后必须确认页码或唯一结果集合变化。

### 2. 视频详情与评论

1. 点击一个尚未访问的视频时同时等待新 `Page`；若没有新页面，再检查当前页导航和站内弹层。
2. 在实际承载详情的页面执行登录提示守卫，读取标题、UP 主、简介、播放数据、发布时间和标签。
3. 滚动到评论区域。递归进入所有开放的 `shadowRoot`，识别评论线程、主评论、回复和登录截断提示。
4. 使用可观察的评论或线程身份、作者与文本组合去重；父级文本包含子级文本时不得重复计数。
5. 保存已渲染的有限评论并明确 `visible_count`、页面展示总数与 `truncated_by_login`。总数不是已获取数量。
6. 关闭详情标签页并回到原搜索页，验证页码、滚动位置和已访问集合仍然有效，再处理下一个视频。

### 3. 专栏

- 在专栏搜索标签中保存当前页公开呈现的标题、作者、摘要、统计和链接。
- 打开详情后如果只有登录壳或正文为空，记录 `article_body_login_blocked` 并返回结果页。
- 只有真实页面重新验证正文存在时，才增加正文提取；不得用搜索摘要冒充全文。

### 4. 漫游与本地追加

- 每个资源使用平台类型与稳定 ID 作为幂等键，统一观察对象交给总控追加；总控更新已有条目，不生成重复副本。
- 每条记录至少关联来源 URL、提取时间、页面元数据、可见评论、截断原因和本地证据引用。
- 运行合同支持按结果数、按时长和持续漫游。持续漫游不设固定视频数或页数上限，只在 owner 人工停止、验证码或安全门禁、连续多轮无新增、分页耗尽、浏览器退出或网络失败时结束。
- 分页耗尽只代表当前关键词当前结果集合结束。持续模式可从配置的其他关键词或公开入口继续；没有下一入口时记录 `source_exhausted`，不得空转。

## 证据与隐私

每次运行建立时间戳目录，使用 `summary.json`、`events.jsonl`、当前视口截图、脱敏 HTML 和有限文本摘要记录事实。为搜索页、详情页、评论区、分页前后和登录截断分别保存阶段证据。

禁止保存 HAR 请求体、Cookie、Authorization、localStorage 值、签名参数、完整媒体文件或完整带查询参数的 URL。页面证据只保留复核结构和提取结果所需的最小内容，并确保 `.xhs-probe/` 不进入 Git。

## 失败处理

- 定位、点击或等待失败时先保存现场，再依据刚读取的结构最多尝试 3 种已解释候选。
- 搜索提交后没有结果变化、新视频页无法识别、Shadow DOM 关闭或文章只显示登录壳时，记录对应边界并结束当前资源分支。
- 新标签页捕获失败时同时检查现有页面集合与旧页 URL，不重复点击同一个视频制造多个标签页。
- 验证码、安全校验、频率提示、强制登录墙、页面关闭或浏览器断开时立即停止自动操作，不刷新或切换入口规避限制。

## 验证与交付

1. 在真实匿名页面完成一次可见搜索，记录关键词、唯一结果数和结果页形态。
2. 验证至少一次分页前后结果集合变化，以及一次点击视频后的新标签页捕获。
3. 保存视频元数据、递归 Shadow DOM 评论结果和登录截断依据；分别报告 DOM 节点数、去重评论数与页面展示总数。
4. 验证专栏搜索摘要，并把专栏详情正文可读与登录阻断分开报告。
5. 检查 `.xhs-probe/` 已被忽略且工作区不包含会话资料或探针证据。
6. 修改项目实现时执行最接近变更的测试；更新本 skill 后运行 `skill-creator` 的 `quick_validate.py`。

交付时区分仓库静态检查、真实页面验证和未验证能力。未真实运行的页面能力不得写成已支持。
